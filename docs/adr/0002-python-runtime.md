# ADR-0002 — In-browser Python runtime
**Context:** R-LAB-01 mandates browser Python (WASM) in a Web Worker, never main thread, with time/memory guards.
**Decision:** Pyodide pinned to exact version **0.27.7**, self-hosted from `public/vendor/pyodide/` (vendored dist; the CDN URL in `src/lib/runtime/protocol.ts` exists only as a documented fallback constant and is NOT used by the worker — the sandbox environment blocks cross-origin loads and R-ARC-09 prefers no external origins). Runs in a dedicated classic Worker (`public/pyodide-worker.js`). Per-run time limit 10s default, enforced by a **per-run watchdog that hard-terminates the worker and respawns lazily on the next run** (the only reliable interrupt without `SharedArrayBuffer`; COOP/COEP were deliberately NOT adopted — they would break the sandbox routing of ADR-0007 and offer no benefit over terminate+respawn here). stdout/stderr captured and relayed as worker events. `sqlite3` is vendored as a pinned wheel from the same 0.27.7 dist, sha256-verified at load, and FS-preloaded together with `public/py-modules/minigrad.py` (M3, ADR-0008).
**M5 correction note (2026-10-19):** the original text of this ADR said "0.28.x" and mentioned a `SharedArrayBuffer` interrupt flag and matplotlib-canvas rendering. Reality shipped differently and this revision records the as-built truth: 0.27.7, watchdog terminate+respawn (zero `SharedArrayBuffer` references in the worker), and no vendored matplotlib — the plotting chapters (D2L) teach with pure-Python numeric exercises instead; an unvendored matplotlib would violate R-ARC-09's no-unaudited-origins bar. Version pinning policy: bump the wheel + `pyodide-lock.json` together, re-run the Pyodide regression harness (`scripts/test_pyodide_minigrad.ts`), then re-verify one lesson E2E.
**Consequences:** Tier A covers PY4E ch1–16 fully; ML/NN lessons use our NumPy-free scalar autograd (M3, ADR-0008) — not scikit-learn/torch.
