# ADR-0003 — Spaced-repetition scheduler
**Context:** R-MAS-02 requires FSRS or SM-2, choice recorded.
**Decision:** **FSRS-4.5** (open algorithm, per-card stability/difficulty) with calm-mode caps (daily queue ≤20). Params embedded in `gamification.config.ts` — no magic numbers (R-GAM-01).
**Consequences:** Slightly more state per card than SM-2; better retention for code cards; implement pure-TS with unit tests.
