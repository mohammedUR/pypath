# ADR-0006 — Part I track ordering (R-CUR decision)
**Context:** Spec suggests interleaving practical SWE skills early.
**Decision:** P1 order = PY4E ch1→10 as-is (book pedagogy), with "Pro Habit" callouts from SWE. P3 interleave: after PY4E ch5 (loops) insert Git-basics mini-track; after ch10 insert testing+static-checks mini-track; full SWE depth (requirements/architecture/security/metrics) after P2. Order encoded in `curriculum/graph.json`.
**Consequences:** Learners meet tooling before capstone; SWE chapters still 100% covered.
