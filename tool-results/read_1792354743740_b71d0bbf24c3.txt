   258→14.2 Fine-Tuning
   259→In earlier chapters, we discussed how to train models on the Fashion-MNIST training
   260→dataset with only 60000 images. We also described ImageNet, the most widely used large-
   261→scale image dataset in academia, which has more than 10 million images and 1000 objects.
   262→However, the size of the dataset that we usually encounter is between those of the two
   263→datasets.
   264→Suppose that we want to recognize different types of chairs from images, and then recom-
   265→mend purchase links to users. One possible method is to first identify 100 common chairs,
   266→take 1000 images of different angles for each chair, and then train a classification model
   267→on the collected image dataset. Although this chair dataset may be larger than the Fashion-
   268→MNIST dataset, the number of examples is still less than one-tenth of that in ImageNet.
   269→This may lead to overfitting of complicated models that are suitable for ImageNet on this
   270→chair dataset. Besides, due to the limited amount of training examples, the accuracy of the
   271→trained model may not meet practical requirements.
   272→In order to address the above problems, an obvious solution is to collect more data. How-
   273→ever, collecting and labeling data can take a lot of time and money. For example, in order
   274→to collect the ImageNet dataset, researchers have spent millions of dollars from research
   275→funding. Although the current data collection cost has been significantly reduced, this cost
   276→still cannot be ignored.
   277→Another solution is to apply transfer learning to transfer the knowledge learned from the
   278→source dataset to the target dataset. For example, although most of the images in the Ima-
   279→geNet dataset have nothing to do with chairs, the model trained on this dataset may extract
   280→more general image features, which can help identify edges, textures, shapes, and object
   281→composition. These similar features may also be effective for recognizing chairs.
   282→14.2.1 Steps
   283→In this section, we will introduce a common technique in transfer learning: fine-tuning. As
   284→shown in Fig. 14.2.1, fine-tuning consists of the following four steps:
   285→1. Pretrain a neural network model, i.e., the source model, on a source dataset (e.g., the
   286→ImageNet dataset).
   287→2. Create a new neural network model, i.e., the target model. This copies all model de-
   288→signs and their parameters on the source model except the output layer. We assume that
   289→these model parameters contain the knowledge learned from the source dataset and this
   290→
   291→===== صفحة الكتاب 641 =====
   292→601
   293→Fine-Tuning
   294→knowledge will also be applicable to the target dataset. We also assume that the output
   295→layer of the source model is closely related to the labels of the source dataset; thus it is
   296→not used in the target model.
   297→3. Add an output layer to the target model, whose number of outputs is the number of
   298→categories in the target dataset. Then randomly initialize the model parameters of this
   299→layer.
   300→4. Train the target model on the target dataset, such as a chair dataset. The output layer
   301→will be trained from scratch, while the parameters of all the other layers are fine-tuned
   302→based on the parameters of the source model.

   306→When target datasets are much smaller than source datasets, fine-tuning helps to improve
   307→models’ generalization ability.

   592→14.4 Anchor Boxes
   593→Object detection algorithms usually sample a large number of regions in the input image,
   594→determine whether these regions contain objects of interest, and adjust the boundaries of
