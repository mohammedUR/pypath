   665→17.3.4 The “Self-correcting” Property of Q-Learning
   666→The dataset collected by the robot during Q-Learning grows with time. Both the exploration
   667→policy 𝜋𝑒and the estimate ˆ𝑄evolve as the robot collects more data. This gives us a key
   668→insight into why Q-Learning works well. Consider a state 𝑠: if a particular action 𝑎has
   669→a large value under the current estimate ˆ𝑄(𝑠, 𝑎), then both the 𝜖-greedy and the softmax
   670→exploration policies have a larger probability of picking this action. If this action actually is
   671→not the ideal action, then the future states that arise from this action will have poor rewards.
   672→The next update of the Q-Learning objective will therefore reduce the value ˆ𝑄(𝑠, 𝑎), which
   673→will reduce the probability of picking this action the next time the robot visits state 𝑠. Bad

   679→actions, e.g., ones whose value is overestimated in ˆ𝑄(𝑠, 𝑎), are explored by the robot but
   680→their value is correct in the next update of the Q-Learning objective. Good actions, e.g.,
   681→whose value ˆ𝑄(𝑠, 𝑎) is large, are explored more often by the robot and thereby reinforced.
